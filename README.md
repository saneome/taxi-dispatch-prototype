# Служба заказа такси

Учебный прототип на Java 17, Spring Boot и PostgreSQL с веб-интерфейсом на Яндекс Картах и дорожными маршрутами Mapbox. Показывает расчёт цены, подбор водителя, оформление заказа и симуляцию поездки. Автопарк, проверки допуска и расчёты демонстрационные. В src/python находится процедурная реализация алгоритмов.

## Запуск

1. Установите Docker с Docker Compose.
2. Скопируйте .env.example в .env. Укажите свои ключи Яндекс Карт и геокодера и токен Mapbox Directions. Файл .env хранится локально.
3. В корне проекта выполните `docker compose up --build`.
4. Откройте [веб-интерфейс](http://localhost:8080). Выберите точки подачи и назначения, затем тариф и автомобиль.

PostgreSQL получает схему и демонстрационные данные при первом создании тома из src/java/src/main/resources/db/init.sql.

## Проверки

- Python: `python -m unittest discover -s src/python -v`.
- Java (JDK 17 и Maven): `mvn -f src/java/pom.xml test`.
- Клиентский сценарий (Node.js): `node --test src/java/src/test/js/road-movement.cjs`.

Тесты запускаются без рабочих ключей картографических сервисов.
